## 📂 Struktur Proyek

```
portfolio-website/
│
├── css/                      # Stylesheet
│   ├── home.css              # Style untuk homepage
│   ├── about.css             # Style untuk halaman about
│   ├── porto.css             # Style untuk halaman portfolio
│   ├── contact.css           # Style untuk halaman kontak
│   ├── opening.css           # Style untuk animasi loading
│   ├── aboutskill.css        # Style untuk section skill
│   ├── playporto.css         # Style untuk preview portofolio
│   └── mobile/               # Style khusus versi mobile
│       ├── mobilehome.css    # Home mobile
│       ├── mobileabout.css   # About mobile
│       ├── mobileporto.css   # Portfolio mobile
│       └── mobilecontact.css # Contact mobile
│
├── js/                       # Script JavaScript
│   ├── loading.js            # Animasi loading dan inisialisasi
│   ├── home.js               # Script untuk homepage
│   ├── about.js              # Script untuk halaman about
│   ├── porto.js              # Script untuk halaman portfolio
│   └── mobile/               # Script khusus mobile
│       ├── home.js           # Home mobile script
│       ├── porto.js          # Portfolio mobile script
│       └── mobileabout.js    # About mobile script
│
├── img/                      # Aset gambar dan visual
│   ├── edu/                  # Gambar pendidikan
│   ├── porto/                # Gambar portfolio
│   ├── skill/                # Ikon skill
│   └── workex/               # Gambar pengalaman kerja
│
├── index.html                # Halaman beranda
├── about.html                # Halaman tentang
├── porto.html                # Halaman portfolio
├── contact.html              # Halaman kontak
├── thanks.html               # Halaman terima kasih
└── README.md                 # Dokumentasi proyek
```

## 📊 Sections & Features

### 🏠 Home Page
- **Animasi Grid Opening** - Transisi pembuka yang menarik
- **Particles Background** - Efek partikel interaktif
- **Typing Animation** - Efek mengetik dinamis dengan Typed.js
- **Responsive Layout** - Adaptif untuk semua ukuran layar
- **Hover Effects** - Interaksi hover yang responsif

### 👨‍💼 About Page
- **Timeline Pendidikan** - Visualisasi kronologis pendidikan
- **Timeline Pengalaman** - Detail pengalaman kerja dengan layout timeline
- **Skill Bars** - Indikator visual kemampuan teknis
- **AOS Animations** - Animasi berbasis scroll

### 🖼️ Portfolio Page
- **Kategori Proyek** - Pengelompokan berdasarkan jenis keahlian
- **Gallery View** - Tampilan gallery yang responsif
- **Modal Preview** - Preview proyek dalam modal box
- **Video Integration** - Integrasi video dari berbagai sumber

### 📩 Contact Page
- **Form Kontak** - Form kontak yang terintegrasi dengan validasi
- **Social Media Links** - Tautan media sosial dengan icon
- **GitHub Stats** - Visualisasi aktivitas GitHub
- **Thank You Page** - Halaman konfirmasi setelah pengiriman form

## 💻 Instalasi & Penggunaan

1. **Clone Repository**
   ```bash
   git clone https://github.com/ayyi858/portfolio-website.git
   ```

2. **Buka Project**
   ```bash
   cd portfolio-website
   ```

3. **Jalankan Secara Lokal**
   - Buka file `index.html` di browser Anda
   - Atau gunakan ekstensi Live Server di VS Code

4. **Live Demo**
   - Kunjungi [web-portofollio-ayproductions.vercel.app](https://web-portofollio-ayproductions.vercel.app/)
